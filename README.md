## 1. 核心架构

- **动态市场效率自适应滤波**：根据资产价格位移效率动态识别单边趋势环境，过滤震荡噪点。
- **分层多维头寸管理机制**：底仓波段利润保护与极值单边趋势追踪兼顾，捕获长尾收益。
- **无滞后保本锁定与动态追踪保护**：建立动态安全垫机制，行情展开后自动保护初始本金。
- **离散单合约连续性映射与主动移仓**：基于真实市场流动性迁移进行跨期平旧开新，全真计入滑点与摩擦成本。

## 4. 快速上手与运行验证

### 运行环境要求
- **操作系统**：Windows 10 / 11 64-bit (x86_64)
- **Python 运行时**：Python 3.11 64-bit

### 安装基础依赖
```bash
pip install -r requirements.txt
```

### 数据输入格式规范 (Data Schema Specifications)

系统回测输入数据规范：

1. **行情数据文件夹 (`--data-dir`)**：
   - **命名规范**：`{SYMBOL}_daily.csv`（例如 `AU_daily.csv`, `CU_daily.csv`, `SC_daily.csv` 等，大写代码）。
   - **必需字段**：
     | 字段名 | 说明 |
     | :--- | :--- |
     | `date` | 交易日期（`YYYY-MM-DD`） |
     | `open` | 当日开盘价 |
     | `high` | 当日最高价 |
     | `low`  | 当日最低价 |
     | `close`| 当日收盘价 |

2. **多资产基差与物理合约映射文件 (`--basis-file`)**：
   - 驱动物理级主动移仓状态机（默认文件名 `ALL_SPOT_BASIS_DAILY.csv`）。
   - **必需字段**：`symbol`、`date`、`dom_contract`、`dom_price`、`dom_basis_rate`。

### 执行回测验证
1. **运行 500 万元机构标准版验证**（推荐）：
   ```bash
   python run_acts90_demo.py --capital 5000000
   ```

2. **运行 100 万元小资金实盘对照验证**：
   ```bash
   python run_acts90_demo.py --capital 1000000
   ```

3. **自定义路径与滑点参数**：
   ```bash
   python run_acts90_demo.py --capital 5000000 --data-dir "path/to/back_adjusted" --basis-file "path/to/ALL_SPOT_BASIS_DAILY.csv" --slip 2.0
   ```
